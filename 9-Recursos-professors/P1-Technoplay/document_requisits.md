## 4 · La llista de requisits

**Aquest és el nucli del document.** Un requisit és una cosa que el sistema **ha de fer** quan estigui acabat. No és el que teniu ara, ni com ho fareu: és què ha de passar perquè el client digui que sí.

| *Regla d'or: si no sabeu com comprovar-ho, no és un requisit. És un desig, i els desitjos no es poden defensar davant un client.* |
| --- |

**Exemples de la diferència:**

| Això NO és un requisit | Això SÍ que ho és |
| --- | --- |
| Que els ordinadors vagin millor | Cap ordinador no es reinicia durant 4 hores seguides de partida |
| Que el full de càlcul sigui fàcil d'usar | La Laura fa una reserva sencera en menys de 3 minuts amb el manual |
| Que la xarxa sigui segura | Des de la wifi de convidats no es pot arribar al PC de recepció |

Ompliu la taula. Poseu tants requisits com calgui, però cap requisit repetit i cap requisit que no vingui del client.

| # | El sistema ha de... | Com ho comprovarem | Imprescindible o desitjable | D'on surt |
| --- | --- | --- | --- | --- |
| R1 | | | | |
| R2 | | | | |
| R3 | | | | |
| R4 | | | | |
| R5 | | | | |
| R6 | | | | |

*Columna «Com ho comprovarem»: descriviu una acció concreta i el resultat que espereu. Ha de ser una cosa que es pugui fer davant el client, en pocs minuts, i que ell entengui sense explicacions.*

*Columna «Imprescindible o desitjable»: si el pressupost no arriba per a tot, els desitjables són els primers que cauen. Penseu-hi bé, perquè haureu de justificar-ho.*

*Columna «D'on surt»: escriviu on ho heu llegit (bloc de la fitxa) o «cal preguntar-ho» si encara no ho sabeu del cert.*

columna «Com ho comprovarem», una per una, davant seu.
